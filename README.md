# Operly

AI-powered business operating platform for small businesses. Manage customers, sales, tasks and quotations in one workspace, with an AI assistant that handles the busywork.

## Stack

Next.js, TypeScript, Tailwind CSS. Planned: Neon (PostgreSQL), Better Auth, Vercel Blob, deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

## Status

Step 1 of the build: project foundation, design system and public landing page. Authentication, database and the core workspace follow.
